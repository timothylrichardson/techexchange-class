# Project rules

These course materials are evergreen. Never add cohort dates, days of the week, clock times, venues, room numbers, or partner-site names to any page or handout, even if a source document or request includes them. Use relative wording instead: Hour 1, 50 min, Class 1.

Follow "Keeping the materials evergreen" in README.md, and run `python3 scripts/check-evergreen.py` before committing. Remove details from the source. Do not hide them with CSS.

Keep README.md current when pages or structure change.
